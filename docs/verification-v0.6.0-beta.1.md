# 0.6.0-beta.1 검증 기록

2026-09-21, Windows x64, .NET 8.0.27, WebView2 Runtime 153.0.4234.48.

- 경고를 오류로 처리하는 Release 빌드 성공.
- 개발 빌드 71개 통과: `artifacts/youtube-chat-fixed/results.json`.
- 자체 .NET 런타임을 포함한 배포 빌드 1차: 기존 FFmpeg 자막 프레임 캡처 1개 시간 초과. 새 기능 검사는 통과.
- 동일 배포 바이너리 재검사 71개 통과: `artifacts/v0.6.0-beta.1-published-recheck/results.json`. 일부 캡처가 느렸으며 간헐적 지연의 원인은 미확정.
- 자막 없는 로컬 영상에서 외부 SRT를 AI 대상으로 잘못 선택하지 않는지 확인. 내장 한국어 트랙 3개와 자막 지연 보정 확인.
- API 목적지·모델·구조화 응답·store:false·한글 텍스트 직렬화·토큰 표시 검사. 잘못된 자막 ID, 부분/거절 응답, 인증/한도 오류, 취소와 창 닫기 후 늦게 도착한 답변 검사.
- DPAPI 저장·복호화·삭제는 테스트 전용 디렉터리에서 수행. 실제 사용자 키를 읽거나 사용하지 않았으며 API는 대체 응답으로 검사.
- 긴 자막의 전송 예산과 영상 후반부 후보 포함 확인.
- 설치된 WebView2에서 합성 페이지의 표시된 자막을 읽고 실제 HTML video를 2.2초로 이동. 광고 상태·숨겨진 자막 패널·다른 영상 ID 거부 확인.
- 실제 Chrome의 공개 YouTube 영상 두 개는 정상 재생됐지만, 스크립트 패널은 비어 있어 실사이트 자막 연동을 검증하지 못함. WebView2의 실제 YouTube 재생과 API까지 연결한 종단 간 검증은 완료되지 않음.

검사 프로그램은 `scripts/test.ps1`로 실행합니다. 실제 OpenAI 호출, YouTube 로그인과 영상별 제한, 물리적 마우스/DPI 검사는 이 결과에 포함되지 않습니다.
