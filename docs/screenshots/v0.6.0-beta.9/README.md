# 0.6.0-beta.9 화면

- `01-api-settings.png`: 실제 API 설정 창. 격리된 테스트 키를 Windows DPAPI로 저장한 상태이며, 실제 키와 유료 API 응답은 포함하지 않습니다.
- `02-chat-ready.png`: 실제 채팅 UI에 합성 자막 3개가 자동으로 연결된 상태. 테스트 키를 사용하며 실제 사용자 키는 표시하지 않습니다.

이미지는 앱의 WPF 렌더 결과입니다. API 저장 확인과 API 연결 확인은 서로 다른 상태입니다. 연결 확인 기능은 별도 통합 검사와 실제 API 요청으로 검증했습니다.
