# 0.6.0-beta.2 화면과 검증

- `01-address-bar.png`: 실제 WPF 메인 화면. 항상 표시되는 주소창과 기본 미니멀 UI.
- `02-youtube-chat.png`: 실제 유튜브 영상과 `gpt-5.4-mini` API로 검증한 채팅 패널. 한국어 스크립트 301개를 읽고 일반 질문에서는 재생 위치를 유지했으며 후속 이동 요청으로 10:45에 도달했습니다. 이동 자체에는 추가 API 호출이 없습니다.
- `03-bottom-layout.png`: 840×620 최소 창의 하단 채팅 배치 검사. 브라우저 영역에 합성 레이아웃 검사 화면이라고 명시했습니다. 실제 영상 재생 캡처가 아닙니다.

WPF UI는 RenderTargetBitmap, 실제 브라우저 표면은 WebView2 CapturePreviewAsync로 같은 창의 좌표에 맞춰 합성했습니다. 네이티브 브라우저 표면이 WPF 렌더링에 포함되지 않기 때문입니다. UI나 답변을 이미지 생성으로 만들지 않았습니다.

실제 테스트 영상: https://www.youtube.com/watch?v=wRgJPO_qIT4

일반 자동 검사에서는 실제 API 키를 읽거나 유료 요청을 보내지 않습니다. `.env`를 사용하는 실제 검사는 별도 실행 옵션으로만 수행하고, 키는 저장소·스크린샷·배포물에 넣지 않습니다.
