# 신플레이어 0.5.0 기능 화면

릴리스 소개에 사용하는 실제 UI와 캡처 결과입니다.

- 기준: `v0.5.0`, 앱 소스 커밋 `a8b14fb9146d79b18c880f43429ec70f81714f55`.
- `01-boost-and-speed.png`: +12 dB 증폭과 1.5배속을 선택한 실제 재생 컨트롤.
- `02-boost-menu.png`: 실제 증폭 단계 선택 메뉴. 최대 단계 선택 상태.
- `03-ui-picker.png`: 실제 UI 선택 창과 네 가지 미리보기.
- `04-capture-completed.png`: 6초 데모 MP4의 한국어 내장 자막을 선택하고 실제로 3장을 저장한 완료 화면.
- `05-captured-frame-*.png`: 해당 작업이 출력한 PNG 원본. 자막 중간 시점 1·3·5초의 프레임.

UI 이미지는 동일한 앱 소스의 WPF 컨트롤을 별도의 로컬 렌더 실행에서 2배 해상도로 저장했습니다. 데스크톱 전체 스크린샷이나 영상 영역을 합성한 이미지가 아닙니다. 표시된 메뉴·설정·작업 완료 상태는 실제 앱 로직으로 생성했습니다. 사용자 설정과 재생 기록은 격리했으며, 완료 화면의 저장 경로는 공개 데모 전용 경로입니다.

데모 영상은 `scripts/create-test-media.py`가 만든 합성 영상입니다. 빨강·초록·파랑 장면에 한국어와 영어 텍스트 자막 트랙이 내장되어 있습니다. 사진 세 장은 한국어 트랙을 선택한 결과이며, 외부 영상·사용자 녹화·개인 파일은 포함하지 않습니다.
